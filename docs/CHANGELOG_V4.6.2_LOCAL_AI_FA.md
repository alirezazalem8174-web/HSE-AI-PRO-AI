# HSE AI PRO 4.6.2 — Local AI Visual Inspector

## قابلیت جدید

یک ماژول هوش مصنوعی تصویری کاملاً محلی به برنامه اضافه شد:

- مدل انتخاب‌شده: **Gemma 4 E2B IT** در قالب LiteRT-LM
- اجرای تحلیل روی خود دستگاه با Google LiteRT-LM
- بدون API پولی، بدون کلید API و بدون ارسال تصویر برای سرویس استنتاج ابری
- تصویر با یک Prompt تخصصی HSE تحلیل می‌شود و خروجی شامل موارد ناایمن، خطر/پیامد، اقدام اصلاحی، اولویت و موارد غیرقابل تشخیص است.
- برای جلوگیری از انباشته‌شدن تاریخچه تصویر، برای هر عکس یک Conversation جدید ساخته می‌شود.
- تلاش اولیه برای GPU و در صورت خطای قابل‌گرفتن، fallback به CPU انجام می‌شود.
- مدل به‌صورت On-Demand دانلود می‌شود و داخل APK قرار نگرفته است.
- دانلود قابلیت Resume دارد و پس از پایان، حجم و SHA-256 مدل بررسی می‌شود.
- مدل با یک فایل marker معتبر در اجراهای بعدی دوباره SHA-256 کامل نمی‌شود مگر marker نامعتبر باشد.
- سقف تصویر ورودی ۲۰MB است.
- اگر دستگاه کمتر از حدود ۸GB RAM داشته باشد، تحلیل با این مدل اجرا نمی‌شود تا از فشار حافظه و Crash جلوگیری شود.

## نکته هزینه و اینترنت

استنتاج مدل رایگان و محلی است و هزینه API ندارد. فقط اولین دریافت مدل حدود ۲.۶GB اینترنت نیاز دارد؛ پس از نصب مدل، تحلیل تصویر بدون اینترنت انجام می‌شود.

## محدودیت ایمنی

این قابلیت ابزار کمکی برای شناسایی بصری است و جایگزین بازدید حضوری، ارزیابی ریسک، استانداردها، دستورالعمل‌های کارخانه یا نظر مسئول HSE نیست. مدل عمومی است و برای کاربرد HSE اختصاصاً Fine-tune نشده؛ بنابراین خروجی باید توسط کارشناس بررسی شود.

## QA

تست اختصاصی `tools/qa_local_ai.py` اضافه و در GitHub Actions فعال شد. این تست وابستگی LiteRT-LM، مدل pinned، SHA-256، مسیر دانلود، محدودیت تصویر، fallback، عدم وجود API پولی و قرارداد UI را بررسی می‌کند.
