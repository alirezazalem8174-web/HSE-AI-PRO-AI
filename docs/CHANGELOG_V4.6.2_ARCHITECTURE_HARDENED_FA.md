# HSE AI PRO 4.6.2 — Architecture Hardening

## هدف
کاهش ریسک خطا در پوسته معماری جدید، بدون مهاجرت پرریسک به Compose یا تغییر همزمان لایه داده.

## اصلاحات
- `HseFeatureCoordinator` اکنون ثبت صریح Feature در Navigator را بر View بازگشتی از `build()` مقدم می‌داند.
- این اصلاح یک خطای بالقوه مهم را حذف می‌کند: برخی Featureهای فعلی پس از ثبت View اصلی، یک فاصله یا Footer به `content` اضافه می‌کردند و Coordinator می‌توانست آخرین View را به‌اشتباه به عنوان مقصد Navigation ثبت کند.
- کلیدهای تکراری Feature دیگر بی‌صدا جایگزین نمی‌شوند.
- کلیدهای تکراری Navigation نیز بی‌صدا جایگزین نمی‌شوند.
- قراردادهای `contains()`، `size()` و `clear()` برای تست‌پذیری و مدیریت چرخه عمر اضافه/تقویت شدند.
- هنگام Navigation، اگر View از والد خود جدا شده باشد، عملیات اسکرول متوقف می‌شود.
- سازنده‌های Coordinator و Navigator ورودی‌های ضروری `null` را زودتر رد می‌کنند.

## تست
QAهای معماری، Syntax و Preflight پس از اصلاح دوباره اجرا شدند. Build واقعی Android فقط در محیطی دارای Android SDK قابل تأیید است و در این محیط ادعای موفقیت Build نمی‌شود.
