# HSE AI PRO 4.6.4 — AI Stability & Regression Hardening

## هدف
پس از ورود Gemma/LiteRT-LM و زنجیره AI→HSE→Risk→Report→PDF، یک بازبینی ریشه‌ای روی مسیر AI، چرخه‌حیات، ورودی تصویر، نسخه‌بندی و Build Gate انجام شد.

## اصلاحات
- جلوگیری از شروع دانلود مدل چندگیگابایتی روی دستگاه نامناسب از نظر RAM.
- جلوگیری از اجرای تحلیل AI روی Thread اصلی Android.
- اعتبارسنجی فرمت/ابعاد تصویر قبل از ورود به موتور AI.
- حفظ سقف 20MB برای فایل تصویر و افزودن کنترل تعداد پیکسل برای جلوگیری از فشار حافظه.
- هماهنگ‌سازی نسخه برنامه با 4.6.4 / versionCode 59.
- افزودن QA صریح برای AI HSE Pipeline و Risk Library/NCR به GitHub Actions.
- اضافه شدن مرحله compileDebugJavaWithJavac به Build Gate پیش از lint/assemble.
- اصلاح QA قدیمی که هنوز نسخه 4.6.2/4.6.3 را انتظار می‌کشید.

## وضعیت مهم
QAهای استاتیک و قراردادی پروژه PASS هستند؛ اما در محیط فعلی Android SDK و Gradle 8.7 در دسترس نیست، بنابراین APK واقعی در این محیط ادعای Build موفق ندارد. Build واقعی باید در GitHub Actions/Codespaces اجرا و نتیجه آن بررسی شود.

## مدل AI
Gemma 4 E2B IT در LiteRT-LM با همان SHA-256 مورد انتظار پروژه نگه داشته شده و مدل داخل APK بسته‌بندی نمی‌شود؛ دانلود و اعتبارسنجی در اولین استفاده انجام می‌شود.
