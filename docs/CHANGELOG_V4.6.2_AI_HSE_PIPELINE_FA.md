# تغییرات مرحله AI → HSE → Risk → Inspection → PDF

## تکمیل زنجیره بازرسی هوشمند
- خروجی متنی Gemma 4 E2B به یافته ساختاریافته HSE تبدیل می‌شود.
- هر یافته شامل دسته، شاهد قابل مشاهده، وضعیت تشخیص، خطر/پیامد، اقدام فوری، اقدام اصلاحی، اولویت و اطمینان است.
- ثبت یافته فقط پس از تأیید کاربر انجام می‌شود؛ AI به‌تنهایی یافته را قطعی نمی‌کند.
- یافته ثبت‌شده می‌تواند با تأیید کاربر وارد ارزیابی ریسک ۵×۵ شود.
- احتمال و شدت پیشنهادی AI فقط مقدار اولیه هستند و کاربر باید آنها را بازبینی/اصلاح کند.
- ارتباط بین یافته و ریسک در دیتابیس ذخیره می‌شود.
- گزارش بازرسی از یافته‌های ثبت‌شده ساخته می‌شود.
- گزارش بازرسی مستقیماً به PDF تبدیل و از طریق انتخاب محل ذخیره، روی دستگاه ذخیره می‌شود.

## دیتابیس
- نسخه دیتابیس از ۱۱ به ۱۲ ارتقا یافت.
- جدول `inspection_findings` اضافه شد.
- برای کاربران قدیمی، جدول در `onUpgrade` با `CREATE TABLE IF NOT EXISTS` ساخته می‌شود و اطلاعات قبلی حفظ می‌گردد.
- Backup/Restore نسخه ۱۲ را پشتیبانی و ستون‌های اصلی یافته‌ها را اعتبارسنجی می‌کند.

## کنترل کیفیت
- تست اختصاصی `qa_ai_hse_pipeline.py` اضافه شد.
- کل مجموعه QA موجود پس از تغییرات دوباره اجرا شد و PASS شد.
- محیط فعلی این جلسه Android SDK/Gradle کامل برای build واقعی APK ندارد؛ بنابراین APK محلی تولید نشده است. Build واقعی همچنان باید در GitHub Actions با JDK 17 و Gradle 8.7 انجام شود.
