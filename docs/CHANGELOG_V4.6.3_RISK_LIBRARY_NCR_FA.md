# HSE AI PRO 4.6.3 — کتابخانه یافته‌های HSE، مقایسه تصویر و NCR

- ارتقای دیتابیس از Schema 12 به 13 با حفظ مهاجرت تراکنشی نسخه‌های قدیمی.
- افزودن کتابخانه محلی یافته‌های بازرسی HSE با جست‌وجو و فیلتر.
- امکان انتخاب دو یافته دارای تصویر و مقایسه بصری کنار هم.
- افزودن ثبت Non-Conformance Report (NCR) به‌صورت کاملاً آفلاین.
- ثبت شماره یکتای NCR، شرح عدم انطباق، مرجع/الزام، اقدام فوری، اقدام اصلاحی و مسئول اقدام.
- پشتیبانی از NCR در Backup/Restore.
- بدون API پولی، سرور، Firebase یا سرویس ابری اجباری.
- QA اختصاصی Risk Library/NCR و رگرسیون تست‌های مهاجرت، Backup/Restore، Persistence و چرخه حیات.

## محدودیت مهم
مقایسه تصویری ابزار کمکی است و تشخیص نهایی، احراز عدم انطباق و تصمیم اصلاحی باید توسط مسئول HSE/بازرس ذی‌صلاح تأیید شود.
