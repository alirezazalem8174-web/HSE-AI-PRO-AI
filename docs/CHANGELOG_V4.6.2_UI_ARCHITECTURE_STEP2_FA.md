# نسخه ۴.۶.۲ — گام دوم معماری رابط کاربری

## هدف
جداکردن زبان بصری و ناوبری از منطق Featureها، بدون مهاجرت پرریسک به Compose یا بازنویسی هم‌زمان دیتابیس و AI.

## تغییرات
- ایجاد `HseUiTheme` به‌عنوان Design System مرکزی برای رنگ‌ها، کارت‌ها، دکمه‌ها، Badge، ورودی‌ها، تایپوگرافی و گرادیان‌ها.
- حذف پراکندگی تصمیمات رنگ و اجزای پایه UI از سطح Featureها و نگه‌داشتن APIهای قبلی `MainActivity` به‌عنوان لایه سازگاری.
- ایجاد `HseSectionNavigator` برای ثبت و پیمایش بخش‌های اصلی صفحه به‌جای وابستگی مستقیم Featureها به مختصات ScrollView.
- حفظ RTL، مقیاس فونت و پوسته فعلی.
- عدم تغییر Schema دیتابیس، موتور AI، Backup/Restore و Reminder.

## گام بعدی
جداسازی Feature Controllerها از `MainActivity` به‌صورت مرحله‌ای، با تست رگرسیون بعد از هر Feature؛ بدون مهاجرت یک‌باره به معماری جدید.
