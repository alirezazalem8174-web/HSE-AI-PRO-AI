# تغییرات نسخه ۴.۶.۲ — پوسته حرفه‌ای HSE AI PRO

## هدف
ارتقای پوسته بصری برنامه از یک رابط ساده و کم‌هویت به یک رابط حرفه‌ای، صنعتی و قابل توسعه، بدون مهاجرت پرریسک کل پروژه به معماری UI جدید.

## تغییرات
- ایجاد هویت بصری متمرکز برای HSE AI PRO با پالت Navy / Teal / Cyan / Red / Amber.
- هدر حرفه‌ای شامل نام محصول، توضیح سامانه، وضعیت Offline و کنترل اندازه متن.
- داشبورد با کارت‌های آماری رنگی و تفکیک‌شده برای منابع، یادداشت‌ها، ریسک‌های بالا و رویدادهای باز.
- بخش «دسترسی سریع» برای کتابخانه، یادداشت، ریسک و حوادث.
- افزایش عمق بصری کارت‌ها با گوشه‌های نرم، حاشیه کنترل‌شده و elevation.
- استفاده از badge و gradient برای ایجاد hierarchy بصری بهتر.
- حفظ RTL، قابلیت تغییر اندازه متن و تمام مسیرهای فعلی برنامه.
- عدم تغییر منطق دیتابیس، Backup/Restore، Reminder و موتور هوش مصنوعی در این مرحله.

## نکته معماری
این مرحله عمداً «پوسته UI» را از تغییر گسترده معماری داده و منطق برنامه جدا نگه می‌دارد تا ریسک regression پایین بماند. مرحله بعدی می‌تواند جداسازی Featureها و ViewModel/Repositoryها باشد.

## QA
تمام QAهای موجود پروژه پس از تغییرات اجرا شدند و PASS شدند، شامل source syntax، preflight، HSE knowledge، local AI، migration، persistence، backup/restore، concurrency، reminder و adversarial.

## محدودیت Build
در محیط توسعه فعلی Android SDK/Gradle نصب نیست؛ بنابراین Build واقعی APK در این محیط انجام نشده است. Build نهایی باید در GitHub Actions با toolchain تعریف‌شده پروژه تأیید شود.
